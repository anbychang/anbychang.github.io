Time Limit: 3 sec per test case
Score: 20 points

Problem Statement

You are given integer sequences A = (A1, ..., AN) and B = (B1, ..., BM).

A pair of sequences (C, D) is valid if C is a subsequence of A, D is a subsequence of B, |C| = |D|, and |Ci − Di| ≤ 1 for every 1 ≤ i ≤ |C|.

Among all valid pairs, maximize |C|. If several choices attain this length, output the lexicographically largest C.

A subsequence is obtained by deleting zero or more elements without changing their order. At the first position where two sequences differ, the one with the larger element is lexicographically larger.

Constraints

  • 1 ≤ N, M ≤ 1500
  • 0 ≤ Ai, Bj ≤ 9 for all valid indices.

Input

The lengths N and M are determined by the number of integers on each line.

A1 ... AN
B1 ... BM

Output

Print the elements of C on one line, separated by spaces. If no elements can be chosen, print an empty line.

Sample Input 1

2 5 7 9 4 1 3
3 5 4 5 7 3

Sample Output 1

2 5 7 4

The maximum length is 4. C = (2, 5, 7, 4) is larger than another valid answer (2, 5, 4, 3) at the first different element.

Sample Input 2

0 9 0
0 0 9

Sample Output 2

0 9

Both (0, 9) and (0, 0) are valid choices for C with length 2. The former is lexicographically larger.

Sample Input 3

9 0 9 0
8 1 8 1

Sample Output 3

9 0 9 0
