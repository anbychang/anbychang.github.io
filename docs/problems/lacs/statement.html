Time Limit: 3 sec per test case
Score: 20 points

Problem Statement

You are given two integer sequences S1 and S2. A subsequence is formed by deleting zero or more elements without changing the order of the remaining elements.

Choose a subsequence A of S1 and a subsequence B of S2. They must have the same length, and |A[i] - B[i]| ≤ 1 at every position.

Maximize their length. If several choices have the maximum length, print the lexicographically largest A. To compare two sequences, look at their first different element; the sequence with the larger element is lexicographically larger.

Constraints

  • Each sequence contains between 1 and 1500 integers.
  • Every element is an integer between 0 and 9.

Input

The input is given in the following format. The first line contains S1, and the second line contains S2. Integers on each line are separated by spaces.

S1[1] S1[2] ... S1[n]
S2[1] S2[2] ... S2[m]

Output

Print the selected subsequence A on one line, with spaces between its elements. If no elements can be paired, print an empty line.

Sample Input 1

2 5 7 9 4 1 3
3 5 4 5 7 3

Sample Output 1

2 5 7 4

A = [2, 5, 7, 4] can be paired with B = [3, 5, 7, 3]. Their length is 4, which is maximum. Among all valid choices of length 4, this A is lexicographically largest.
