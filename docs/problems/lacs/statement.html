Time Limit: 3 sec per test case
Score: 20 points

Problem Statement

You are given two sequences of integers: S1 = (s1,1, ..., s1,L₁) of length L1, and S2 = (s2,1, ..., s2,L₂) of length L2. A subsequence is obtained by deleting zero or more elements without changing the order of the remaining elements.

Choose a subsequence S1′ = (s′1,1, ..., s′1,K) of S1 and a subsequence S2′ = (s′2,1, ..., s′2,K) of S2. Both have length K. For every integer i with 1 ≤ i ≤ K, they must satisfy |s′1,i − s′2,i| ≤ 1.

Maximize K. If several choices have the maximum length, print the lexicographically largest S1′. Two sequences of equal length are compared at the first position where they differ; the one with the larger element is lexicographically larger.

Constraints

  • 1 ≤ L1, L2 ≤ 1500
  • Every element of S1 and S2 is an integer between 0 and 9.

Input

The input is given in the following format. The first line contains S1 and the second line contains S2. Each line contains space-separated integers.

s1,1 s1,2 ... s1,L₁
s2,1 s2,2 ... s2,L₂

Output

Print the elements of S1′ on one line, separated by spaces. If K = 0, print an empty line.

Sample Input 1

2 5 7 9 4 1 3
3 5 4 5 7 3

Sample Output 1

2 5 7 4

One valid pair is S1′ = (2, 5, 7, 4) and S2′ = (3, 5, 7, 3). Here K = 4, the maximum possible length. Among the choices of this length, the shown S1′ is lexicographically largest.
