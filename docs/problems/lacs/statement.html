Given two integer sequences S1 and S2, choose a subsequence from each. The chosen subsequences must have the same length. At every position, the two values must differ by at most 1.

Make the length as large as possible. If several subsequences have that length, output the lexicographically largest subsequence chosen from S1.

Input

The input has two lines. Each line contains a space-separated sequence. Each sequence has 1 to 1500 values, and every value is between 0 and 9.

Output

Print the chosen subsequence from S1 on one line, with spaces between values. If no values can be matched, print an empty line.

Sample Input
2 5 7 9 4 1 3
3 5 4 5 7 3
Sample Output
2 5 7 4
