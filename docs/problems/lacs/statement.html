Time Limit: 3 sec per test case
Score: 20 points

Problem Statement

You are given two integer sequences S1 and S2 of lengths L1 and L2. Let s1,i be the i-th element of S1, and s2,j the j-th element of S2. A subsequence is formed by deleting zero or more elements while keeping the original order.

Choose a subsequence S1′ of S1 and a subsequence S2′ of S2, both of length K. Let s′1,i and s′2,i be their i-th elements. For every 1 ≤ i ≤ K, require:

|s′1,i − s′2,i| ≤ 1

First, maximize K. Among all choices with the maximum length, print the lexicographically largest S1′. Compare two sequences at their first different element; the one with the larger element is lexicographically larger.

Constraints

  • 1 ≤ L1, L2 ≤ 1500
  • Every element of S1 and S2 is an integer between 0 and 9.

Input

The input is given in the following format. The first line contains S1 and the second line contains S2. Each line contains space-separated integers.

s1,1 s1,2 ... s1,L₁
s2,1 s2,2 ... s2,L₂

Output

Print the elements of S1′ on one line, separated by spaces. If K = 0, print an empty line.

Sample Input 1

2 5 7 9 4 1 3
3 5 4 5 7 3

Sample Output 1

2 5 7 4

The maximum length is K = 4. One valid pair is S1′ = (2, 5, 7, 4) and S2′ = (3, 5, 7, 3).

Another length-4 choice for S1′ is (2, 5, 4, 3). The first difference is the third element, where 7 > 4, so the sample output is lexicographically larger.
