Time Limit: 3 sec per test case
Score: 20 points

Problem Statement

You are given two integer sequences S1 and S2. A subsequence is formed by deleting zero or more elements while keeping the original order.

Choose a subsequence S1′ of S1 and a subsequence S2′ of S2 with the same length. Let S1′i and S2′i be their elements at position i, counted from 1. For every position i, require:

|S1′i − S2′i| ≤ 1

First, make the common length as large as possible. Among all choices with that length, print the lexicographically largest S1′. Compare two sequences at their first different element; the one with the larger element is lexicographically larger.

Constraints

  • Each of S1 and S2 contains between 1 and 1500 elements.
  • Every element of S1 and S2 is an integer between 0 and 9.

Input

The first line contains S1, and the second contains S2. Each line lists its integers separated by spaces.

S1
S2

Output

Print the elements of S1′ on one line, separated by spaces. If no elements can be chosen, print an empty line.

Sample Input 1

2 5 7 9 4 1 3
3 5 4 5 7 3

Sample Output 1

2 5 7 4

The maximum length is 4. One valid pair is S1′ = (2, 5, 7, 4) and S2′ = (3, 5, 7, 3).

Another length-4 choice for S1′ is (2, 5, 4, 3). The first difference is the third element, where 7 > 4, so the sample output is lexicographically larger.
