Time Limit: 3 sec per test case
Score: 20 points

Problem Statement

Given two integer sequences S1 and S2, choose subsequences S1′ and S2′ of equal length. For every position i, starting at 0, require |S1′[i] − S2′[i]| ≤ 1.

Maximize their length. If several answers have that length, output the lexicographically largest S1′. A subsequence keeps the original order. At the first different element, the larger value wins.

Constraints

  • Each of S1 and S2 contains between 1 and 1500 elements.
  • Every element of S1 and S2 is an integer between 0 and 9.

Input

The first line contains S1, and the second contains S2. Each line lists its integers separated by spaces.

S1
S2

Output

Print the elements of S1′ on one line, separated by spaces. If no elements can be chosen, print an empty line.

Sample Input 1

2 5 7 9 4 1 3
3 5 4 5 7 3

Sample Output 1

2 5 7 4

The maximum length is 4. S1′ = (2, 5, 7, 4) is larger than another valid answer (2, 5, 4, 3) at the first different element.

Sample Input 2

0 9 0
0 0 9

Sample Output 2

0 9

Both (0, 9) and (0, 0) can be chosen from S1 with length 2. The former is lexicographically larger.

Sample Input 3

9 0 9 0
8 1 8 1

Sample Output 3

9 0 9 0
