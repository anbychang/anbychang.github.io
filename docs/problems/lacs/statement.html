Time Limit: 3 sec per test case
Score: 20 points

Problem Statement

You are given two integer sequences A and B of lengths N and M, respectively.

Choose a subsequence C of A and a subsequence D of B. The two subsequences must have the same length and satisfy the following condition for every 1 ≤ i ≤ |C|:

|Ci − Di| ≤ 1

Among all valid choices, print a sequence C of maximum length. If there are several such sequences, print the lexicographically largest one. A sequence is lexicographically larger if its first differing element is larger.

Notes

A subsequence is obtained by removing zero or more elements without changing the order of the remaining elements.

Constraints

  • 1 ≤ N, M ≤ 1500
  • 0 ≤ Ai ≤ 9 for 1 ≤ i ≤ N.
  • 0 ≤ Bj ≤ 9 for 1 ≤ j ≤ M.

Input

Input is given from Standard Input in the following format:

A1 ... AN
B1 ... BM

The lengths N and M are determined by the number of integers on each line.

Output

Print the elements of C on one line, separated by spaces. If no elements can be chosen, print an empty line.

Sample Input 1

2 5 7 9 4 1 3
3 5 4 5 7 3

Sample Output 1

2 5 7 4

We can choose C = (2, 5, 7, 4) and D = (3, 5, 7, 3). No valid sequence is longer than 4. Another choice is C = (2, 5, 4, 3), but it is lexicographically smaller.

Sample Input 2

0 9 0
0 0 9

Sample Output 2

0 9

Both (0, 9) and (0, 0) can be chosen as C, but (0, 9) is lexicographically larger.

Sample Input 3

9 0 9 0
8 1 8 1

Sample Output 3

9 0 9 0
