Time Limit: 3 sec per test case
Score: 20 points

Problem Statement

You are given two integer sequences S1 and S2. Choose a subsequence S1′ of S1 and a subsequence S2′ of S2 such that:

  • S1′ and S2′ have the same length.
  • Each pair of corresponding elements differs by at most 1.

Maximize their length. If several choices have the same maximum length, print the lexicographically largest S1′. A subsequence keeps the original order. To compare two sequences lexicographically, look at their first different element; the larger one wins.

Constraints

  • Each of S1 and S2 contains between 1 and 1500 elements.
  • Every element of S1 and S2 is an integer between 0 and 9.

Input

The first line contains S1, and the second contains S2. Each line lists its integers separated by spaces.

S1
S2

Output

Print the elements of S1′ on one line, separated by spaces. If no elements can be chosen, print an empty line.

Sample Input 1

2 5 7 9 4 1 3
3 5 4 5 7 3

Sample Output 1

2 5 7 4

The maximum length is 4. One valid pair is S1′ = (2, 5, 7, 4) and S2′ = (3, 5, 7, 3).

Another length-4 choice for S1′ is (2, 5, 4, 3). The first difference is the third element, where 7 > 4, so the sample output is lexicographically larger.

Sample Input 2

0 9 0
0 0 9

Sample Output 2

0 9

Both (0, 9) and (0, 0) can be chosen from S1 with length 2. The former is lexicographically larger.

Sample Input 3

9 0 9 0
8 1 8 1

Sample Output 3

9 0 9 0

All four elements can be chosen: each corresponding pair differs by exactly 1.
