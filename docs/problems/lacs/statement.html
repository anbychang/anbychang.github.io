Time Limit: 3 sec per test case
Score: 20 points

Problem Statement

You are given two integer sequences A = (A1, ..., AN) and B = (B1, ..., BM). Find a longest approximate common subsequence C. If there are multiple such sequences, print the lexicographically largest one.

Notes

A sequence C is an approximate common subsequence of A and B if C is a subsequence of A and there is a subsequence D of B such that |C| = |D| and |Ci − Di| ≤ 1 for every 1 ≤ i ≤ |C|.

A subsequence is obtained by removing zero or more elements without changing the order of the remaining elements. Among sequences of equal length, the one with the larger element at the first different position is lexicographically larger.

Constraints

  • 1 ≤ N, M ≤ 1500
  • 0 ≤ Ai, Bj ≤ 9 for all valid indices.

Input

Input is given from Standard Input in the following format:

A1 ... AN
B1 ... BM

The lengths N and M are determined by the number of integers on each line.

Output

Print the elements of C on one line, separated by spaces. If no elements can be chosen, print an empty line.

Sample Input 1

2 5 7 9 4 1 3
3 5 4 5 7 3

Sample Output 1

2 5 7 4

The maximum length is 4. C = (2, 5, 7, 4) is larger than another valid answer (2, 5, 4, 3) at the first different element.

Sample Input 2

0 9 0
0 0 9

Sample Output 2

0 9

Both (0, 9) and (0, 0) are valid choices for C with length 2. The former is lexicographically larger.

Sample Input 3

9 0 9 0
8 1 8 1

Sample Output 3

9 0 9 0
