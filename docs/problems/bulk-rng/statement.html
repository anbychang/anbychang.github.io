Time Limit: 3 sec per test case

Problem Statement

There are n bits b0, b1, ..., bn−1 arranged in a circle. You are also given s distinct offsets d1, ..., ds.

In one step, every bit is updated simultaneously. The new value of bit i is

b(i+d1) mod n ⊕ b(i+d2) mod n ⊕ ... ⊕ b(i+ds) mod n,

where each bit on the right is taken from before the step, and ⊕ denotes XOR. Indices start at 0.

Find the bit string after exactly T steps.

Constraints

  • 1 ≤ n ≤ 2 × 105
  • 1 ≤ s ≤ min(n, 10)
  • 1 ≤ T ≤ 1018
  • 0 ≤ dj < n for 1 ≤ j ≤ s; all offsets are distinct.
  • The initial bit string has length n and contains only 0 and 1.

Input

Input is given from Standard Input in the following format:

n s T
d1 ... ds
b0b1...bn−1

The last line is one bit string with no spaces.

Output

Print the resulting bit string on one line.

Sample Input 1

5 2 1
1 4
10000

Sample Output 1

01001

Sample Input 2

5 2 1000000000000
1 4
10110

Sample Output 2

00110

Sample Input 3

4 2 3
0 2
1000

Sample Output 3

0000

After two steps, every bit is 0, because each source bit is XORed with itself.
