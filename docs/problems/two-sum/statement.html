Time Limit: 3 sec per test case

Problem Statement

You are given N integers A1, A2, …, AN and an integer X. Find two indices i and j such that 1 ≤ i < j ≤ N and Ai + Aj = X.

At least one valid pair exists. If there are several valid pairs, print any one of them.

Constraints

  • 2 ≤ N ≤ 2000
  • −109 ≤ Ai ≤ 109 for every i.
  • All input values are integers.

Input

The input is given in the following format:

N X
A1 A2 ... AN

Output

Print two 1-based indices i and j, separated by a space, satisfying 1 ≤ i < j ≤ N and Ai + Aj = X.

Sample Input 1

4 9
2 7 11 15

Sample Output 1

1 2

A1 + A2 = 2 + 7 = 9 = X, so (i, j) = (1, 2) is a valid answer.
