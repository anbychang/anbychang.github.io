Time Limit: 3 sec per test case

Problem Statement

You are given an integer array nums and an integer target. Find two different elements of nums whose sum is target, then print their positions.

At least one valid pair exists. You may choose any valid pair.

Constraints

  • The length of nums is between 2 and 2000.
  • Each value in nums is between −109 and 109.
  • All input values are integers.

Input

Let N be the length of nums.

The input is given in the following format:

N target
nums1 nums2 ... numsN

Output

Print the two 1-based positions in increasing order, separated by a space. This judge uses 1-based positions; the original LeetCode problem uses 0-based indices.

Sample Input 1

4 9
2 7 11 15

Sample Output 1

1 2

The first two values are 2 and 7. Their sum is 9, so positions 1 and 2 are a valid answer.
