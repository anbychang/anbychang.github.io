Time Limit: 3 sec per test case

Problem Statement

Given an integer sequence A of length N and an integer X, find indices i and j such that 1 ≤ i < j ≤ N and Ai + Aj = X.

At least one answer exists. Any valid pair is accepted.

Constraints

  • 2 ≤ N ≤ 2000
  • −109 ≤ Ai ≤ 109 for every i.

Input

The input is given in the following format:

N X
A1 A2 ... AN

Output

Print i and j in increasing order, separated by a space.

Sample Input 1

4 9
2 7 11 15

Sample Output 1

1 2

Sample Input 2

2 6
3 3

Sample Output 2

1 2

The two 3s are at different indices.

Sample Input 3

3 800
327 575 473

Sample Output 3

1 3

A1 + A3 = 327 + 473 = 800.
