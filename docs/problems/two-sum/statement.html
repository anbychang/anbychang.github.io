Time Limit: 3 sec per test case

Problem Statement

Given an integer array nums and an integer target, find two distinct 1-based indices i and j such that nums[i] + nums[j] = target.

At least one answer exists. Any valid pair is accepted.

Constraints

  • The length of nums is between 2 and 2000.
  • Each value in nums is between −109 and 109.

Input

Let N be the length of nums.

The input is given in the following format:

N target
nums[1] nums[2] ... nums[N]

Output

Print i and j in increasing order, separated by a space.

Sample Input 1

4 9
2 7 11 15

Sample Output 1

1 2

Sample Input 2

2 6
3 3

Sample Output 2

1 2

The two 3s are at different indices.

Sample Input 3

3 800
327 575 473

Sample Output 3

1 3

nums[1] + nums[3] = 327 + 473 = 800.
