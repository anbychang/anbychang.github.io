Time Limit: 3 sec per test case

Problem Statement

You are given an array nums of N integers and an integer target. Find two indices i and j such that 1 ≤ i < j ≤ N and numsi + numsj = target.

At least one valid pair exists. If there are several valid pairs, print any one of them.

Constraints

  • 2 ≤ N ≤ 2000
  • −109 ≤ numsi ≤ 109 for every i.
  • All input values are integers.

Input

The input is given in the following format:

N target
nums1 nums2 ... numsN

Output

Print two 1-based indices i and j, separated by a space, satisfying 1 ≤ i < j ≤ N and numsi + numsj = target.

Sample Input 1

4 9
2 7 11 15

Sample Output 1

1 2

nums1 + nums2 = 2 + 7 = 9 = target, so (i, j) = (1, 2) is a valid answer.
