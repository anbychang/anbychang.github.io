Time Limit: 3 sec per test case

Problem Statement

You are given an array a of n integers and an integer target. Find two different indices i and j such that a[i] + a[j] = target.

At least one valid pair exists. If several pairs are valid, you may print any one of them.

Constraints

  • 2 ≤ n ≤ 2000
  • -109 ≤ a[i] ≤ 109
  • All input values are integers.

Input

The input is given in the following format:

n target
a[1] a[2] ... a[n]

Output

Print two 1-based indices i j such that 1 ≤ i < j ≤ n and a[i] + a[j] = target.

Sample Input 1

4 9
2 7 11 15

Sample Output 1

1 2

The values at positions 1 and 2 are 2 and 7. Their sum is 9.
