Given an array of integers and a target value, find two different positions whose values add up to the target.

Input

The first line contains n target. The second line contains n integers. At least one valid pair exists. 2 ≤ n ≤ 2000, and each value is between -109 and 109.

Output

Print any valid pair of 1-based indices i j with i < j.

Sample Input
4 9
2 7 11 15
Sample Output
1 2
